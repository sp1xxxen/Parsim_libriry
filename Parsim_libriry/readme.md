# Парсим библиотеку

Проект написан для получения обложек для книг и текста.

## О проекте

В основном данный проект, используется для работы с книжным сайтом, где можно работать с каждой книгой на этом сайте.

## Как установить

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

## Как Запустить проекта

Скачайте репозиторий с гитхаба. Загрузите репозиторий в Visual  Studio Code и запустите проект, скачав нужные библиотеки, которые описаны в начале проекта.
Для того чтобы запустить проект в терминал нужно написать 
```
python main.py
```

## Цель проекта

Код написан в образовательных целях для школы Третье Место.
